
# Website of CODING CLUB, SATI

Welcome to the official repository for the **CODING CLUB, SATI Website**! This platform serves as the central hub for our college's developer community, featuring upcoming events, coding challenges, project showcases, and a member directory.

Built by students, for students. 💻✨

**NOTE**: This repo is dedicated to handle frontend only. To access backend code for this website, visit [coding-club-backend](https://github.com/CodingClub-SATI/Coding-club-backend)


---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js
* **Build Tool:** Vite
* **Routing:** React Router DOM
* **Styling:** CSS
* **Icons:** Lucide React
* **Hosting/Deployment:** Vercel

---

## ✨ Features

* **Event Tracker:** Stay updated with upcoming hackathons, coding contests, and workshops.
* **Leaderboard:** Displays rankings from our weekly club coding challenges.
* **Project Showcase:** A space for club members to display their open-source projects.
* **Resources:** Handpicked roadmaps and study materials for DSA, Web Dev, and AI/ML.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/) (v18.x or higher recommended)
* [Git](https://git-scm.com/)

### Installation & Setup

1. **Clone the repository:**
```bash
    git clone https://github.com/CodingClub-SATI/Coding-club-frontend-v1.git
    cd Coding-club-frontend
```

2. **Install dependencies:**
```bash
    npm install
```

3. **Run the development server:**
```bash
    npm run dev
```

Open [http://localhost:5173](http://localhost:5173) (Vite's default port) in your browser to see the result.

## 🤝 Open Source Contributing

We love contributions from the community! To keep our codebase clean and stable, we follow a strict branching strategy and code review process.

Before you start writing code, please read our **[Contribution & Branching Guidelines](CONTRIBUTING.md)**.

### Quick Start:

1. **Fork the repository** by clicking the "Fork" button at the top right of this page.

2. **Clone your fork locally:**
```
    git clone https://github.com/YOUR-USERNAME/Coding-club-frontend.git`
```

3. **Add the original repository as an upstream remote** to keep your fork synced:
```
    git remote add upstream https://github.com/CodingClub-SATI/Coding-club-frontend.git
```

4. **Create a feature branch:** `git checkout -b feature/your-awesome-feature`
5. **Make your changes** and ensure the app builds successfully (`npm run build`).
6. **Commit using conventional messages:** `git commit -m 'feat: add dark mode toggle'`
7. **Push to your fork:** `git push origin feature/your-awesome-feature`
8. **Open a Pull Request** on our main repository targeting the `dev` branch.

Note: Please make sure to follow our coding standards and ensure there are no rendering errors before submitting a PR.
